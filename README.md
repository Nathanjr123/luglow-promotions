# Luglow Promotions website (prototype)

Static site: `index.html`, `styles.css`, `main.js`. No build step.
`map-data.js` is a dot grid made from Natural Earth's public-domain outline of South Africa.
The site is set to `noindex` until it is approved; remove that meta tag in `index.html` at launch.

Fonts in `fonts/` (Anybody, Instrument Sans) are under the SIL Open Font License.
Photos in `img/` were supplied by Luglow Promotions.
